System Architecture & Engineering Details

VocalFlow is built for high-performance real-time speech transcription specifically handling multilingual code-switching (Hinglish: Hindi + English).

🎙️ Real-Time Audio Pipeline

  • Web Audio API AnalyserNode 60fps dynamic visualizer
  • Continuous interim streaming with WebSocket sync
  • MediaRecorder audio chunking for local voice playback
  • Zero-latency client-side multilingual recognition

🗄️ Database & Storage

  • PostgreSQL 17 Relational Database (Dockerized container)
  • Auto-reconnecting SQLAlchemy ORM connection pool
  • Seamless fallback to SQLite if PostgreSQL container stops
  • Full CRUD with indexing, search, filtering, and export

🗣️ Multilingual / Hinglish Engine

  • Lexical Hindi and English code-switch detection
  • Devanagari Unicode & Romanized Hinglish vocabulary parsing
  • Language ratio computation (Hindi % vs English %)
  • Code-switch transition point counter

🔊 Open-Source Text-to-Speech

  • Self-contained open-source gTTS speech synthesis
  • MD5 hash based audio caching for zero-latency replay
  • Automatic Indian English / Hindi accent voice selection
  • Browser Web Speech Synthesis fallback integration
